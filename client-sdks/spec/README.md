These are the source files for the generated `ogx-client` Python SDK (see `../openapi`).

- `openapi.yml`: the OpenAPI specification for the OGX API.
- `resources.yml`: the resource-hierarchy configuration that maps resources to endpoints. The `../openapi` pipeline reads its `resources:` tree to build the client's method hierarchy.

Both files are regenerated by `scripts/run_openapi_generator.sh`:

- `openapi.yml` comes from the FastAPI-based spec generator.
- `resources.yml` is rendered from `scripts/openapi_generator/resources_config/generate_resources.py` so the resource mapping stays in lock-step with the spec.
