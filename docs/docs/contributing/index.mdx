# Contributing to OGX

We want to make contributing to this project as easy and transparent as
possible.

The canonical contributing guide lives in the repository's
[CONTRIBUTING.md](https://github.com/ogx-ai/ogx/blob/main/CONTRIBUTING.md). It covers
setting up your development environment, pre-commit hooks, the issue and pull request
process, how to add a new provider, coding style, and common tasks. Read it before you
start contributing.
