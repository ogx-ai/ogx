# Experimental APIs

OGX exposes its experimental APIs under the `v1alpha` prefix. They are
functional and available for use, but they may change in breaking ways
between releases.

:::warning
Experimental APIs may introduce breaking changes in minor releases. Pin your
client version if stability is important for your use case.
:::

## v1alpha APIs

### Admin API
Server administration: health and version checks, provider listing, route
inspection, and management of external connectors (such as MCP servers) and
their tools.

**Endpoint prefix:** `v1alpha/admin`

### Interactions API
Google Interactions-compatible endpoint for streaming interactive sessions.

**Endpoint prefix:** `v1alpha/interactions`

### Skills API
Register, list, version, update, and delete skills uploaded to the server.

**Endpoint prefix:** `v1alpha/skills`

### Containers API
Manage container workloads, including uploading and retrieving files inside
a container.

**Endpoint prefix:** `v1alpha/containers`

### File Processors API
Submit asynchronous jobs that parse and chunk documents for vector storage,
and poll or cancel those jobs. The synchronous
`v1alpha/file-processors/process` endpoint is deprecated in favor of the
jobs endpoints.

**Endpoint prefix:** `v1alpha/file-processors`

### Inference Rerank
Rerank documents for search relevance.

**Endpoint:** `v1alpha/inference/rerank`
